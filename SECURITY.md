## 1. Security Vulnerabilities Identified & Fixed

| ID | Severity | Vulnerability | Root Cause in Production Bundle | Remediation Implemented |
| :--- | :--- | :--- | :--- | :--- |
| **SEC-01** | **Medium** | Missing HTTP Security Headers & Server Fingerprinting | Production response headers exposed `X-Powered-By: Express` and lacked `Content-Security-Policy`, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, and `Strict-Transport-Security`. | Implemented [`applySecurityHeaders`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/server.mjs#L27-L49) in [`server.mjs`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/server.mjs), stripping `X-Powered-By` and enforcing strict CSP (`default-src 'self'`, `frame-ancestors 'none'`), `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, and `HSTS`. |
| **SEC-02** | **High** | Unbounded Input, Prompt Injection, & Stored XSS Risk on `POST /api/generate-audit` | Free-text assessment inputs (`businessName`, `currentTools`, `primaryBottleneck`, `customerDropoff`, `suspectedAutomation`) and array items were interpolated directly into LLM prompts without length caps, control-character stripping, or HTML/script tag sanitization. | Built [`validateAndSanitizeAnswers`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/src/validation.mjs#L36-L99) and [`sanitizeText`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/src/validation.mjs#L15-L31) in [`src/validation.mjs`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/src/validation.mjs) enforcing strict enum allowlists, field length limits (`120`–`600` chars), ASCII control character removal, HTML/script tag stripping, and LLM delimiter filtering (`<\|...\|>`, ```` ```system ````). |
| **SEC-03** | **High** | Unthrottled Public LLM Endpoint & Unbounded JSON Body Size | `POST /api/generate-audit` had no per-IP rate limiting or JSON payload size cap, exposing the API key and server to wallet-draining and denial-of-service attacks. | Added per-IP sliding-window rate limiting (`429 Too Many Requests` with `Retry-After`) and a strict `32KB` stream body cap via [`readJsonBody`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/server.mjs#L54-L77) in [`server.mjs`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/server.mjs). |
| **SEC-04** | **Low** | Reverse Tabnabbing on External `window.open` Call | `ImplementationModal` (`mb`) called `window.open("https://wa.me/...", "_blank")` without `"noopener,noreferrer"`, exposing `window.opener` to the target tab. | Patched `window.open` in [`scripts/build-public.mjs`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/scripts/build-public.mjs#L80-L84) and [`public/assets/app.js`](file:///c:/Users/USER/Desktop/MSL%20AI%20OS/projects/auditiq/public/assets/app.js) to pass `"noopener,noreferrer"`. |
